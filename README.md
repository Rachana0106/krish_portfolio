## 📖 About the Project

**Krish Visuals** is a single-page portfolio website created for a photographer, videographer and cinematographer based in Ahmedabad.

The website presents photography services, visual work, image galleries, cinematic videos and contact details in a professional and visually engaging format.

The main goal of this project was to create a portfolio that allows potential clients to:

- Learn about the photographer
- Explore available services
- View photography work
- Watch cinematic videos
- Contact the photographer directly
- Book photography and videography services

## 🚀 How to Run the Project

### Method 1: Open directly

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your browser.

### Method 2: Clone using Git

```bash
git clone https://github.com/Rachana0106/krish_portfolio.git
```

Open the project folder:

```bash
cd krish_portfolio
```

Then open `index.html` in your browser.

### Method 3: Run with VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## ⚠️ Important Notes

The repository contains many image and video files, which may make the project size large.

For better performance:

- Compress images before uploading
- Convert images to WebP
- Compress video files
- Host large videos using YouTube, Vimeo or cloud storage
- Add meaningful `alt` text to every gallery image
- Avoid storing unnecessarily large media files directly in GitHub
